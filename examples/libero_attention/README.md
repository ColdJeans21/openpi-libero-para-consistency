# FM-first instruction-attention intervention

No training or new checkpoint is needed. Reuse `canonical_30k/29999` and
`teacher_consistency_lam1_30k/29999`. First isolate the intervention on FM,
then transfer its locked bias to Teacher. This is an inference diagnostic,
not a claim that fixed attention reweighting is a novel architecture.

## Intervention

Add `beta` to QK logits ONLY for action queries and valid instruction content
keys, in all 18 transformer layers / 8 heads. The original attention mask
still applies afterwards. Vision/text prefix queries, state queries and
prefix KV computation are unchanged. Beta zero returns `None` and takes the
original path. No parameter keys, shapes or initializations are added.
Padding 0, EOS 1, BOS 2 and newline 108 are excluded. Pi0.5 is deliberately
unsupported in v1, because its prompt can contain discrete state tokens.

`beta={0,ln(2),ln(4)}` means multiplying language-to-other *unnormalized odds*
by 1/2/4, not guaranteeing a fixed language attention mass or causal effect.

## Frozen protocol

`manifest_v1.json` freezes two physically matched task pairs (bowl plate/stove,
bottle rack/cabinet), their BDDL and init-state hashes, held-out paraphrases,
10 dev + 20 disjoint test initial states per pair. Four instructions/state:
two goals × canonical/paraphrase. Thus 80 dev or 160 test episodes/condition.
These are seen tasks, so this is not an unseen-task benchmark.

The builder reads the existing fixed Para100 manifest and matches ACT-only
paraphrases to each goal plus physical signature. Selection uses a stable
hash, never success labels. It refuses to overwrite the frozen manifest.

The client restores common XML, fixture arrays, and dynamic state. Model and
initial image/proprio fingerprints must match across goals/wordings/methods.
It explicitly checks both manifest goal predicates; changing the instruction
also changes the success target. Initial states satisfying either goal fail
closed. Policy noise depends only on pair/state/query-index/seed, so it is
matched across instructions, beta and FM/Teacher. Server echoes its digest.

Choose beta on FM dev ONLY: canonical success >= beta0 minus2pp, maximize
both-canonical-goals success, then paraphrase success, then total success;
ties prefer smaller beta. No Teacher or Plus tuning. Lock `selection.json`.
Test FM0/FMselected/Teacher0/Teacherselected; report both-goal and all-four
success rates across 40 test states, plus wrong-goal and episode rates.
If beta0 wins, skip identical selected conditions and record the null result.
Otherwise evaluate selected FM/Teacher on standard Goal100, Para100, Plus410.
The unchanged standard baseline scores are reused; CF baselines are new.

## Queue, safeguards and records

Entry: `scripts/queue_attention_after_residual.sh`; workload:
`scripts/run_attention_study.sh`. The watcher blocks on the current residual
runner's flock and verifies training and ALL on/off evaluations have completed.
It checks queued source SHA256 and both GPUs idle before using them. A failed
dependency or scientific-code change stops the queue instead of bypassing it.
Do not edit a Bash script while that script is running.

CPU regression tests cover bias scope, original mask boundaries, full/cached
velocity equivalence, zero-beta actions/parameter compatibility, beta selection,
controlled noise, goal checker and disjoint manifests. Real-checkpoint GPU
preflight is deliberately deferred to the queue, along with the simulator's
scene audit. A CPU pass is not a claim the GPU/simulation audit already passed.

Reports: `reports/attention/v1/`, logs/status: `logs/attention_v1/`.
No checkpoint is copied, overwritten or pruned. Source commit and file digests
are recorded before queue launch. W&B gets a separate evaluation run; original
training metrics remain intact. Local JSON/CSV/Markdown survives upload failure.
The final queue stage refreshes the global ledger and attempts a scoped report
commit/push, without staging any unrelated worktree files or force pushing.

Global ledger: `reports/ALL_EXPERIMENTS_METHODS_AND_RESULTS.md`, generated by
`scripts/summarize_language_experiments.py`. All main scores use final29999;
partial or missing summaries are left blank and never interpreted as zero.
